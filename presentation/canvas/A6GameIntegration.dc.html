APPENDIX · A6
Putting it in your game
The package
Engine-neutral JSON plus a runtime system prompt. No Unity or Unreal lock-in.
A manifest records the SHA-256 of every file, the input revision, the prompt hash, and the model. The app re-verifies on demand.
Reports export as Markdown plus JSON with source hashes, ready to paste into the coding agent that wires the NPC in.
Tone is a project setting: direction profile, expression intensity, and dialogue mode are layered by world, region, NPC, and quest, and stay out of the compiled character.
The quest contract
fixed
Spoken by the harness verbatim. No model call.
semi-fixed
Generated, but must contain the required evidence words, or falls back.
free
Generated from what the resident actually lived.
events
Idempotent by eventId. Stale AI replies after a stage change are rejected.
stages
Only the game advances a quest stage. Speech never does.
Status: the contract is in-process today and documented in English (QUEST_GAME_ADAPTER.md). An external event API and the first engine adapter are the next step.
