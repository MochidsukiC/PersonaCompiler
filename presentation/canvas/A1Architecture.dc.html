APPENDIX · A1
Architecture
Electron app (Windows)
src/core — schemas, validators, life state machine, spatial rules. No Electron dependency.
src/backend — App Server RPC, real CLI terminals, recovery, memory matcher.
src/main — disk, file watching, save worker thread.
src/renderer — React, Three.js facility view, xterm, relationship graph, review screen.
Codex App Server
One persistent thread per resident, per facility, and one parent.
Residents: typed dynamic tools only, no shell.
Parent: Codex file tools, workspace-write, automatic approval review.
Native compaction, steer, fork, ephemeral recall threads.
Real Codex CLI
A real terminal attaches to any resident's thread.
Goes through an authenticated localhost relay that keeps the resident's tools, model, and effort.
Type mid-turn to steer; close the tab, the resident keeps living.
World state lives in memory; the save worker writes history segments and alternating snapshots, manifest last. After a crash the app reconciles against the Codex threads and reopens read-only.
