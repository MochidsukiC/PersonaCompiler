# 37 — パッケージ全体のファイル比較

制作レビューでは採用記憶・関係を件数で比較します。同じ件数のまま内容が変わった場合や、文章以外の成果物も確認できるよう、manifestに登録された全ファイルを比較する画面とコピー用レポートを追加しました。

## 変更と抽象化

成果物の照合画面で「別のパッケージとファイルを比較」を開き、同じワールド・NPCの別Compilationを基準に選びます。既存の読取専用照合APIで両側を読み、実ファイルのSHA-256を比較します。「両側を再照合して比較」で外部編集後の結果を取得できます。

| 結果 | 意味 |
|---|---|
| 追加 | 現在側だけに登録があり、ファイルを取得できた |
| 削除 | 基準側だけに登録があり、ファイルを取得できた |
| 内容変更 | 両側の実ファイルのhashが異なる |
| 内容一致 | 両側の実ファイルのhashが同じ |
| 比較不能（欠損） | 登録されている側でファイルが欠損している |

パスをキーとするバイト列の比較なので、JSON・文章・スクリプト・画像などに同じ手順を使えます。ゲームのジャンル・エンジン・特定のNPC設定項目の解釈は追加していません。改名は削除と追加になります。manifestに未登録のファイルは対象外です。

「内容一致」と「manifestと一致」は別です。両側とも同じ内容に外部編集されていれば、両者の内容は一致しても元のmanifestとは不一致です。各行の「両側のファイル情報」でこの違いを確認できます。登録ファイルの欠損は削除や一致と推測しません。

「ファイル比較レポートをコピー」は、表示中の比較と両側の全照合記録をMarkdownと`persona-package-comparison/v1`のJSONとして持ち出します。manifestのパス・hash・照合時刻、各ファイルの記録hash・実hash・サイズ・整合性を保持します。コピー時に再照合はしません。各ファイルを個別に読むため、全ファイルが同時点の状態である保証や内容の意味的な比較はありません。

画面確認で、長い照合結果が下部のステータス領域へはみ出す不具合も見つかりました。既存の照合パネルにはflexの高さ制約と内部スクロールがなく、内容が画面領域を押し広げていました。制作レビューと同じ`flex: 1; min-height: 0; overflow: auto`を適用し、ヘッダー・フッターを表示したまま照合結果内をスクロールできるようにしています。

## 試し方

1. `npm run demo:review`で合成資料のデモを起動します。認証やモデル推論は不要です。
2. ファイル一覧から`compilation/current/npcs/sample/manifest.json`を開きます。
3. 「別のパッケージとファイルを比較」を開き、基準に`Compilation baseline`を選びます。
4. 各行の両側の情報を確認し、「ファイル比較レポートをコピー」を試します。
5. 必要ならデモ用フォルダーのファイルを外部編集し、「両側を再照合して比較」で差分を確認します。デモ用資料は実行ごとに隔離されます。

読取境界は既存のIPC送信元検証・manifest Schema・NPCと保存先の一致・Workspaceの実体パス境界を引き継ぎます。比較からファイル書き込み・コマンド実行・外部送信は行いません。共有のコピー操作を除き外部への副作用はなく、ファイル名はReactの文字列表示とMarkdownの引用処理を通します。資格情報は触れません。

実モデル推論・APIキーの使用・既存ワールドの変更はありません。通信や保存ロジックは変更していないため、実CLI接続・保存専用の再検証は今回は対象外です。既知のnative異常終了が解決したとする変更ではありません。
