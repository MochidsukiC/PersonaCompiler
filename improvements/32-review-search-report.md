# 32 — 検索した設定と根拠を制作レビューへ持ち出す

制作レビューの検索結果に「設定の検索レポートをコピー」を追加しました。表示中の設定、その設定が参照する全根拠、検索条件、元資料の参照情報をMarkdownとJSONでコピーできます。

## 制作工程での使い方

たとえば台本の場面IDや翻訳資料の語句で検索すると、その資料から生成されたNPC設定を取り出せます。担当者へ渡すレポートには、該当設定の別の根拠も含めるため、検索語に一致した一部分だけを見て判断することを避けられます。

ゲームの種類、エンジン、資料IDの命名規則に依存する判定はありません。既存の設定本文・見出し／根拠資料／両方の検索をそのまま使います。ゲーム内のルールや設定の正しさを自動判定する機能ではありません。

## 収録内容

- ワールドID、NPC ID・名前、世界revision、生成モデル、採取時刻。
- 読み込んだreview.jsonの相対pathとファイル全体のSHA-256。
- 入力した検索文字列、検索対象、全設定件数と一致件数。
- 表示中の設定と、それらが参照する根拠ID・題名・全文。根拠は重複せず収録します。
- 同じ内容のJSON。形式は`persona-review-search/v1`です。

0件なら0件の条件を記録できます。空の検索条件では全設定を収録します。Runtime Promptや指針はこの検索の対象外です。元ファイルのhashと抜粋JSONのhashを混同しない説明も付けています。ディスク上の最新版ではなく、読み込み済みの資料を記録します。

画面とレポートの検索処理を共通化しました。検索条件を変えるとコピー済みの表示をリセットし、別条件のレポートを既にコピーしたようには表示しません。外部編集をプレビューへ読み込んだ後は、新しい資料・hashでコピーします。

## 試し方

1. `npm run demo:review`で、実モデルを使わない合成資料を開きます。
2. 検索対象を「根拠資料」にし、「全員」などを検索します。
3. 「設定の検索レポートをコピー」を押して、エディターへ貼り付けます。
4. 表示された設定件数、根拠本文、検索条件を確認します。末尾のJSONでも内容を確認できます。

全期間の出来事を持ち出す場合は既存のQAレポート、再生成前後の差分は比較レポートを使います。この機能は、開いている1つの制作レビューに対する検索結果です。
