# 27 — 根拠資料からNPC設定を逆引きする

制作レビューに検索対象の選択を追加しました。設定本文だけでなく、根拠のID・題名・本文から、その資料を参照する設定を探せます。例えば、制作中に問題となった出来事や会話を検索し、どの人格・話し方・行動の設定で根拠として使われているかを確認できます。

## 操作

1. NPCの「制作レビュー」を開きます。
2. 検索対象で「根拠資料」を選び、出来事の語句や資料IDを入力します。
3. 該当資料を参照する設定が表示されます。「根拠 N · 検索一致」を押すと、その根拠の全文を開けます。
4. 設定本文も同時に探す場合は「設定と根拠資料」を選びます。元の「設定本文・見出し」が既定です。

入力の前後の空白を除き、大文字・小文字を区別せず部分一致で検索します。空欄では全設定を表示します。各設定に複数の根拠がある場合、一致した根拠だけに「検索一致」を付け、他の根拠も開ける状態に保ちます。

`npm run demo:review`でも試せます。比較欄を閉じ、キーワード「全員」を入力すると、既定の設定本文検索では0件、「根拠資料」では2件になります。合成の出来事を根拠とした設定を両方表示します。

## 範囲

レビューに保存された資料の文字列と参照関係を検索します。IDの接頭辞、ゲームジャンル、座標形式、ゲームエンジンの種類を固定していません。Runtime Promptなど根拠付き設定以外の本文は検索対象に含みません。資料全体ではなく、開いているNPCのレビュー内が対象です。

文字列が一致した資料を根拠として引用していることは確認できますが、生成の因果関係や解釈の妥当性を判定する機能ではありません。追加の推論・外部通信・依存追加・保存形式変更はありません。
