# 03 — 出来事から調べるSimulation QA

## 変更・試し方

ワールド・関係図の横に「出来事」タブを追加しました。生活のあるワールドで利用できます。

1. 「出来事」を開き、住民・行動種別・ターン・本文を組み合わせて絞り込みます。
2. 住民のフィルターは行動者と受信対象の両方に一致します。
3. 「発話（受信対象0人）」で、その発話の時点で聞き手がいなかった出来事を探せます。
4. 受信対象、声量、発話時の施設・座標を確認できます。住民名を押すと同じ住民の端末が開きます。
5. 「絞り込みを解除」で一覧に戻ります。新しい出来事は現在の絞り込み条件で反映されます。

会話・位置・記憶など複数の要素を持つ生成過程を、出来事から調査できるようにするQA機能です。審査上は実用性・完成度への貢献を狙います。

## 範囲・互換性

検索対象は画面へ届いた直近の履歴です（新形式は最大200件）。全保存履歴を検索したと誤認しないよう画面に明記しています。受信対象は発話時点の対象で、配送完了・既読・記憶化の判定ではありません。

保存形式、AIへの入力、世界の状態遷移、既存の発話配信は変更しません。新しい推論やIPCを追加せず、受信済みsnapshotだけで検索します。閲覧専用のワールドでも利用できます。
